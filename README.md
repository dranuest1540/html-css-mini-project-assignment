# 🎓 TuLearn - Learning Management System

TuLearn adalah website **Learning Management System (LMS)** yang dirancang untuk memberikan pengalaman belajar online yang modern, sederhana, dan responsif. Proyek ini dibuat sebagai landing page LMS yang berfokus pada kemudahan penggunaan (user-friendly) dan siap dikembangkan menjadi platform pembelajaran yang lebih lengkap.

## 🚀 Update (Branch: `project_2`)

Pada update kali ini, beberapa perubahan yang telah dilakukan antara lain:

- ✨ Migrasi styling dari CSS ke **Tailwind CSS**
- 🔐 Menambahkan halaman **Login**
- 📝 Menambahkan halaman **Sign Up**
- 🎨 Meningkatkan tampilan UI agar lebih modern dan responsif
- 📱 Optimalisasi tampilan untuk Desktop, Tablet, dan Mobile

## 🛠️ Tech Stack

- HTML5
- Tailwind CSS
- JavaScript
- Font Awesome
- Google Fonts
